# 寶可夢能力值計算器 (Pokémon EV Calculator)

這是一個專為「舊時代寶可夢對戰」設計的計算與隊伍建立工具。使用者可以透過這個網站輕鬆查詢寶可夢的基礎能力值、計算不同努力值分配下的最終能力值，並建立、分享自己的對戰隊伍配置。

## 🏗️ 專案架構與核心頁面

本專案採用 React 19 搭配 Wouter 進行前端路由管理，主要包含四個核心頁面，分別滿足不同的使用者需求：

### 1. 首頁：寶可夢能力值計算器 (`/`)
這是網站的入口頁面，專注於單隻寶可夢的詳細數據分析與計算，**採用傳統的努力值（EV）系統**。
- **搜尋與展示**：提供直覺的搜尋框，支援中英文名稱與圖鑑編號。搜尋後會展示寶可夢的屬性、特性與種族值雷達圖。
- **能力值計算器 (EV Calculator)**：核心功能區塊。使用者可以設定等級、性格、個體值與努力值，系統會即時計算出最終的實際能力值。
- **圖卡預覽**：在計算器旁會同步顯示該寶可夢的專屬圖卡（MiniTeamSlot），方便使用者隨時預覽並下載。

### 2. 隊伍建立器 - 中文版 (`/champions`)
專為中文使用者設計的隊伍配置頁面，讓玩家可以一次規劃最多六隻寶可夢的完整隊伍。**此頁面不使用努力值系統，而是採用特殊的 66 點 Stat Points (SP) 系統**。
- **SP 系統指南**：內建針對舊時代對戰的 SP（Stat Points）計算說明，幫助玩家掌握 66 SP 的分配限制。
- **隊伍網格 (Team Grid)**：提供六個空位，點擊即可搜尋並加入寶可夢。
- **配置編輯**：每隻加入的寶可夢都可以獨立設定性格、道具、特性與 SP 分配。
- **精美圖卡生成**：每隻寶可夢都會生成一張帶有深色漸層背景、圓角方形頭像與金色外框的高質感圖卡。
- **一鍵匯出**：支援將單隻寶可夢的配置圖卡匯出為 PNG 圖片，方便在社群平台分享。

### 3. 隊伍建立器 - 英文版 (`/champions-en`)
功能與中文版完全相同（同樣採用 66 點 SP 系統），但介面與寶可夢資料（包含名稱、特性、屬性等）皆以英文顯示，滿足國際玩家或習慣使用英文介面的使用者需求。
- **多語系資料處理**：透過 PokéAPI 獲取英文版的資料，並確保多型態寶可夢（如 Galarian 形態）的英文名稱能正確顯示且不被截斷。

### 4. 隊伍建立器 - 傳統 EV 版 (`/team-builder`)
這是一個基於傳統努力值（EV）系統的隊伍建立器，適合習慣現代寶可夢對戰規則的玩家。
- **EV 系統支援**：與首頁的計算器類似，允許玩家為隊伍中的每隻寶可夢分配傳統的 510 點努力值。
- **完整隊伍管理**：提供與 Champions 頁面相同的隊伍網格與配置編輯介面，但底層計算邏輯切換為傳統 EV 系統。

*(註：`/404` 為找不到頁面時的錯誤處理路由，會引導使用者回到首頁。)*

## 🛠️ 技術堆疊與實作細節

- **前端框架**：React 19
- **路由管理**：Wouter (輕量級的 Client-only routing)
- **樣式與 UI**：
  - Tailwind CSS 4 (自訂主題與設計系統，大量使用 CSS 變數進行主題管理)
  - shadcn/ui (提供高品質的基礎 UI 元件，如 Button, Card, Input, Select 等)
  - Lucide React (向量圖示庫)
- **資料來源與處理**：
  - 整合 PokéAPI (`pokeapi.co`) 獲取寶可夢的基礎資料、圖片與多語系名稱。
  - 實作了強大的名稱格式化邏輯 (`formatPokemonName`)，正確處理 Mega 進化、地區型態（如阿羅拉、伽勒爾）等特殊命名規則。
- **圖片匯出**：使用 `html-to-image` 套件將 DOM 元素（MiniTeamSlot）轉換為高畫質的 PNG 圖片。

## 🎨 設計風格與 UI/UX

- **現代化視覺**：採用深色/淺色主題搭配，使用柔和的陰影、圓角與漸層效果，打造「手工打造」的高級質感。
- **響應式設計 (RWD)**：確保在桌面版與手機版上都有良好的瀏覽體驗。特別針對手機版的文字排版進行了優化，例如當寶可夢名稱過長時會自動縮小字體，避免文字被截斷。
- **細節打磨**：
  - 移除了多餘的標題與提示文字，讓畫面保持簡潔。
  - 在隊伍卡片下方加入統一的網站識別（abitingpokedex.com），並使用與外框一致的金色字體，提升品牌一致性。
