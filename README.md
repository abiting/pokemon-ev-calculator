# 寶可夢能力值計算器 (Pokémon EV Calculator)

這是一個專為「舊時代寶可夢對戰」設計的 IV（個體值）、EV（努力值）計算與隊伍建立工具。使用者可以透過這個網站輕鬆查詢寶可夢的基礎能力值、計算不同努力值分配下的最終能力值，並建立、分享自己的對戰隊伍配置。

## 🌟 核心功能

### 1. 寶可夢搜尋與能力值計算
- **快速搜尋**：支援透過寶可夢名稱（中英文）或圖鑑編號進行搜尋。
- **基礎資訊展示**：顯示寶可夢的屬性、特性、種族值等基本資料。
- **能力值計算器**：
  - 支援設定等級（Level）、性格（Nature）、個體值（IVs）與努力值（EVs）。
  - 即時計算並顯示最終的實際能力值（HP、攻擊、防禦、特攻、特防、速度）。
  - 內建「SP（Stat Points）計算指南」，幫助玩家了解舊時代對戰的特殊配點規則（例如：1 SP = 1 實際能力值，總共 66 SP 可供分配）。

### 2. 隊伍建立器 (Team Builder)
- **多語系支援**：提供中文（`/champions`）與英文（`/champions-en`）兩種版本的隊伍建立介面。
- **隊伍卡片預覽 (MiniTeamSlot)**：
  - 為每隻寶可夢生成精美的專屬圖卡，包含頭像、編號、名稱與能力值。
  - 支援多型態寶可夢（如：達摩狒狒、噴火龍 Mega 形態等）的正確名稱與圖片顯示。
  - 採用高質感的深色漸層背景、圓角方形頭像框與金色外框設計。
  - 針對手機版進行了響應式優化，確保長名稱（如 Galarian 形態）能完整顯示不被截斷。
- **一鍵匯出圖片**：使用者可以點擊圖卡右上角的下載按鈕，將單隻寶可夢的配置卡片匯出為 PNG 圖片，方便在社群媒體上分享。

## 🛠️ 技術堆疊

- **前端框架**：React 19
- **路由管理**：Wouter (Client-only routing)
- **樣式與 UI**：
  - Tailwind CSS 4 (自訂主題與設計系統)
  - shadcn/ui (提供高品質的基礎 UI 元件，如 Button, Card, Input, Select 等)
  - Lucide React (圖示庫)
- **資料來源**：整合 PokéAPI 獲取寶可夢的基礎資料、圖片與多語系名稱。
- **圖片匯出**：使用 `html-to-image` 套件將 DOM 元素轉換為圖片。

## 🎨 設計風格與 UI/UX

- **現代化視覺**：採用深色/淺色主題搭配，使用柔和的陰影、圓角與漸層效果，打造「手工打造」的高級質感。
- **響應式設計 (RWD)**：確保在桌面版與手機版上都有良好的瀏覽體驗，特別針對手機版的文字排版與留白進行了細部調整。
- **細節打磨**：
  - 移除了多餘的「DATA SOURCE」與「Share Build」標題，讓畫面更簡潔。
  - 在隊伍卡片下方加入統一的網站識別（abitingpokedex.com），並使用與外框一致的金色字體。
