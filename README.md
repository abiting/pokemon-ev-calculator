# 寶可夢能力值計算器 (Pokémon EV Calculator)

這是一個專為寶可夢對戰玩家設計的網頁應用程式，提供多種能力值計算與隊伍建立工具。專案採用 React 19、Tailwind CSS 4 與 Vite 建構，並整合了 PokéAPI 以獲取最新的寶可夢資料。

## 🌟 核心功能與頁面架構

本專案包含四個主要頁面，分別針對不同的遊戲系統與使用情境設計：

### 1. 舊世代能力值計算器 (Home - `/`)
- **系統**：傳統的**努力值（EV）系統**。
- **語言**：純中文介面。
- **功能**：
  - 專注於單隻寶可夢的能力值計算。
  - 支援搜尋寶可夢、選擇性格、調整個體值（IV）與努力值（EV）。
  - 即時計算並顯示最終的六項能力值（HP、攻擊、防禦、特攻、特防、速度）。

### 2. 新世代能力值計算器 - 中文版 (Champions - `/champions`)
- **系統**：全新的 **66 點 Stat Points (SP) 系統**（取代傳統的努力值系統）。
- **語言**：中文介面。
- **功能**：
  - 專為採用 SP 系統的新遊戲設計。
  - 使用者可以自由分配總共 66 點的 SP 到各項能力值上。
  - 內建精美的 `MiniTeamSlot` 圖卡預覽，可即時檢視配置並匯出為圖片分享。

### 3. 新世代能力值計算器 - 英文版 (Champions EN - `/champions-en`)
- **系統**：全新的 **66 點 Stat Points (SP) 系統**。
- **語言**：英文介面與英文寶可夢資料。
- **功能**：
  - 與中文版 Champions 頁面功能完全相同，但專為英文語系玩家設計。
  - 支援英文搜尋、英文特性與招式顯示。

### 4. 隊伍建立器 (Team Builder - `/team-builder`)
- **系統**：傳統的**努力值（EV）系統**。
- **功能**：
  - 允許玩家建立完整的 6 隻寶可夢隊伍。
  - 每隻寶可夢皆可獨立設定：道具、特性、性格、努力值（EV）以及最多 4 個招式。
  - 提供高質感的隊伍卡片（TeamSlot）展示，支援單隻寶可夢截圖或整支隊伍一鍵匯出為圖片。

## 🎨 UI/UX 設計特色

- **高質感圖卡匯出**：無論是單隻寶可夢的 `MiniTeamSlot` 還是完整的隊伍卡片，皆採用深色漸層背景、圓角設計與金色邊框，並支援一鍵下載為高畫質圖片。
- **響應式設計 (RWD)**：完美適配桌面與行動裝置。在手機版上，長名稱會自動縮小字體以避免裁切，確保截圖排版完美。
- **直覺的搜尋與選擇**：整合 Combobox 與虛擬化列表，即使面對上千種寶可夢、招式與道具，也能保持流暢的搜尋體驗。
- **多型態支援**：完美處理寶可夢的各種地區型態（如伽勒爾、阿羅拉）與特殊型態（如 Mega 進化），並正確顯示對應的圖片與名稱。

## 🛠️ 技術堆疊

- **前端框架**: React 19 + TypeScript
- **建置工具**: Vite
- **路由管理**: Wouter
- **樣式與 UI**: Tailwind CSS 4 + shadcn/ui + Radix UI
- **資料獲取**: TanStack Query (React Query) + PokéAPI
- **圖示**: Lucide React
- **截圖匯出**: modern-screenshot

## 🚀 開發與執行

### 安裝依賴
```bash
pnpm install
```

### 啟動開發伺服器
```bash
pnpm run dev
```

### 建置正式環境版本
```bash
pnpm run build
```
