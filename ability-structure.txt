PokeAPI 特性資料結構（以皮卡丘為例）：

"abilities": [
  {
    "ability": {
      "name": "static",
      "url": "https://pokeapi.co/api/v2/ability/9/"
    },
    "is_hidden": false,
    "slot": 1
  },
  {
    "ability": {
      "name": "lightning-rod",
      "url": "https://pokeapi.co/api/v2/ability/31/"
    },
    "is_hidden": true,
    "slot": 3
  }
]

說明：
- abilities 是陣列，包含該寶可夢的所有特性
- is_hidden: false 表示普通特性
- is_hidden: true 表示隱藏特性（夢特性）
- slot 表示特性的位置
- 需要再呼叫 ability.url 來獲取特性的詳細資訊（包含繁中名稱）
